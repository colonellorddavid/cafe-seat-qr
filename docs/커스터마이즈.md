# 우리 카페에 맞게 바꾸기

**한국어** | [English](CUSTOMIZE_EN.md)

> **가장 쉬운 방법**: [`tools/seat-editor.html`](../tools/seat-editor.html) (좌석 배치 편집기)을 열어 클릭으로 만들고, [복사] → `Code.gs`의 `// ===== 설정 시작` 줄부터 `// ===== 설정 끝` 줄까지를 바꿔 붙여넣으세요. 이미 쓰던 설정은 편집기의 "이미 쓰던 설정 불러오기"로 불러와 이어서 고칠 수 있어요. 아래는 코드를 직접 고치는 방법입니다.

모두 `apps-script/Code.gs` 맨 위 `설정 시작` ~ `설정 끝` 사이에 있습니다. 고친 뒤에는 **저장 → 배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 손님 화면에 반영돼요.

## 1. 카페 이름

```js
const CAFE_NAME = '우리 카페';
```

따옴표 안의 글자만 바꾸세요. 화면 제목과 브라우저 탭 이름에 나옵니다.

## 2. 좌석 배치

```js
const ZONES = [
  { name: '창가 바', note: '조용함',    from: 1,  to: 10, outlet: [1, 10] },
  { name: '2인석',   note: '보통',      from: 11, to: 26, outlet: [11, 18] },
  { name: '4인석',   note: '대화 많음', from: 27, to: 38, outlet: [27, 30] },
  { name: '소파',    note: '대화 많음', from: 39, to: 40, outlet: [0, 0] }
];
```

| 항목 | 뜻 |
| --- | --- |
| `name` | 구역 이름 (화면에 굵게 표시) |
| `note` | 구역 설명 한 마디 (예: 조용함, 노트북 가능) |
| `from`, `to` | 이 구역의 좌석 번호 범위. 실제 테이블에 붙인 번호와 맞추세요 |
| `outlet` | 콘센트가 있는 번호 범위. 없으면 `[0, 0]` |

- 구역은 몇 개든 괜찮아요. 줄을 복사해서 늘리거나 지우면 됩니다. 마지막 줄 뒤에는 쉼표(`,`)를 붙이지 마세요.
- 번호는 **1번부터 빠짐없이 이어지게** 해 주세요 (예: 1–8, 9–20, 21–24). 전체 좌석 수는 자동으로 계산됩니다.
- 콘센트 자리가 띄엄띄엄이면 콘센트 자리끼리 번호가 이어지도록 좌석 번호를 정하는 게 가장 쉬워요.

예시 · 좌석 20개 카페:

```js
const ZONES = [
  { name: '바 좌석', note: '혼자 공부', from: 1,  to: 8,  outlet: [1, 8] },
  { name: '테이블',  note: '2~4인',    from: 9,  to: 20, outlet: [9, 12] }
];
```

## 3. 자동 퇴장 시간

```js
const STAY_MIN = 90;
```

퇴장을 누르지 않은 손님의 자리를 몇 분 뒤에 비울지 정합니다. 스터디카페처럼 오래 머무는 곳이면 180~240으로 늘리세요.

## 4. 한산 / 보통 / 혼잡 기준

```js
const CALM = 0.4, BUSY = 0.75;
```

좌석의 40% 미만이 차 있으면 **한산**, 75% 이상이면 **혼잡**, 그 사이는 **보통**입니다.

## 5. 화면 문구와 색

화면 HTML은 `Code.gs` 아래쪽 `const PAGE = ...` 안에 있습니다. "빈자리(흰색)를 눌러 앉을 자리를 고르세요." 같은 문구는 찾아서 바로 바꿔도 됩니다. 색은 `:root{--accent:#1F6B57; ...}` 줄에서 바꿀 수 있어요.

## 6. 기록 보기와 지우기

- 시트 아래쪽 **좌석기록** 탭에 `시간 · 좌석 · 구분(입장/퇴장)`이 한 줄씩 쌓입니다. 이 탭으로 시간대별 이용 패턴을 분석할 수 있어요.
- 전부 지우려면 Apps Script 편집기에서 함수 목록 → `clearLog` → ▷ 실행.
- 탭 이름을 바꾸면 새 탭이 다시 만들어지니 `좌석기록` 이름은 그대로 두세요.
